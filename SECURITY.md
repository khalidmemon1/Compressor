# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Privacy & Security Model

Compressor is built on a **100% client-side privacy architecture**:
- Images uploaded by users are processed in the user's browser memory (via Web Workers and Canvas APIs).
- Images are never transmitted across the network to any server or cloud storage.
- No personal identifying information or image content is logged.

## Reporting a Vulnerability

If you discover a security vulnerability or privacy concern in Compressor, please do **NOT** open a public issue.

Instead, please send an email to:
**[92.khalidm@gmail.com](mailto:92.khalidm@gmail.com)**

Please include:
- A description of the vulnerability and its potential impact.
- Clear steps to reproduce the issue.
- Any suggested fixes or mitigations.

We will acknowledge receipt within 48 hours and work with you to remediate the issue promptly before disclosure.
